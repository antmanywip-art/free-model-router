## 아직 검증하지 않은 것

- 현재 실제 제공자의 가격·계정 결제 상태와 무료 사용 자격
- 실제 키로 두 제공자를 호출하고 비용 0원 확인
- 공개 HTTPS 경로 및 실제 서버의 TLS 인증서
- OCI 배포·부하·재부팅·운영 자동화
- PDF/HWP 실파일 추출 및 이미지/PDF 직접 전달
- 예약 조사·무료 모델 순위 평가·새 제공자 자동 가입

무료 문서의 런타임 egress 차단과 실제 키 부재 때문에 **1~2단계 전체의 실사용 완료 판정은 보류**합니다. 로컬 구현과 모의 통합 검증은 완료되었습니다. 모델을 임의로 활성화해서 검증을 대신하지 않았습니다.

## 저장과 재현

라우터 소스는 전용 저장소에 저장합니다. 두 클라이언트의 변경은 각각 `codex/personal-router` 브랜치에 있으며 운영/main에 합치지 않았습니다. 현재 클라우드에서 두 비공개 저장소의 읽기는 성공했지만 push 인증은 실패했습니다. 추가 GitHub 쓰기 권한이 적용되기 전까지 해당 커밋은 로컬에만 있습니다.

검증된 패치와 Git bundle은 클라우드의 `/workspace/router-handoff/`에 따로 보존합니다. **이 파일들은 비공개 클라이언트 소스를 포함할 수 있으므로 공개 라우터 저장소에 올리지 않습니다.** 새 작업에서 로컬 전용 커밋이 자동 복원된다고 가정하지 마세요. 기존 클라이언트 저장소 접근·쓰기 권한을 적용하거나, 원래 로컬 Codex에서 패치/bundle을 검토하여 해당 비공개 저장소에 저장해야 합니다.
