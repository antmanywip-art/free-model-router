# 제공자 조사와 활성화

확인일: 2026-10-04 KST. 후보를 폭넓게 관리하되 사용 가능한 무료 경로만 활성화합니다.

## 조사 상태

| 후보 | 우선순위 / 현재 근거 | 다음 확인 |
|---|---|---|
| B.AI | 기존 나라장터·MAGI에서 사용 | 모델별 프로모션과 만료일, 무료 잔액·유료 전환. MAGI 9월 기록의 GLM/DeepSeek 유료 판단을 재확인 |
| OpenRouter | MAGI 기존 연동 | 정확한 무료 모델 ID, 계정 호출 한도, 유료 경로로의 전환 차단 |
| Gemini | 나라장터 기존 연동 | 프로젝트 결제 상태. 과거 비용 발생 사례가 있어 모델명만으로 무료 판정 금지 |
| Groq | OpenAI 호환 후보 | 무료 계정 한도, 현재 모델, JSON 기능 |
| Cerebras | OpenAI 호환 후보 | 무료 계정·지역 자격, 모델·문맥 한도 |
| NVIDIA | OpenAI 호환 후보 | 체험 크레딧/유효기간, 모델별 무료·이용 조건 |
| Mistral | OpenAI 호환 후보 | 무료/실험 요금제와 데이터 취급 조건 |
| Cloudflare Workers AI | 후속 후보 | 계정별 API 경로, 무료 일일 할당량 초과 시 강제 차단 |
| GitHub Models | 후속 후보 | 무료 추론 한도, 개인 서비스 운영 허용 조건 |
| Hugging Face Inference Providers | 후속 후보 | 무료 크레딧 소진 후 동작과 자동 과금 차단 |

공식 조사 URL은 `config/provider_candidates.json`에 있습니다. URL은 조사 출발점이며 최신 가격을 확인했다는 증거가 아닙니다. 첫 8개 문서 요청은 런타임 프록시의 `403 Forbidden`으로 차단됐습니다. Mistral/Hugging Face는 아직 문서를 가져오지 않았습니다. 환경 초안에 문서 도메인을 추가해도 현재 실행 환경에 즉시 적용되는 것은 아닙니다.

제공자 키의 이름/존재를 확인했으며 현재 이 클라우드에는 BAI_API_KEY, BANK_OF_AI_API_KEY, OPENROUTER_API_KEY, GEMINI_API_KEY, GROQ_API_KEY, CEREBRAS_API_KEY, NVIDIA_API_KEY가 없습니다. 다른 기기나 GCP에 있는 키는 이 클라우드로 자동 공유되지 않습니다.

## 최소 실호출 검증에 필요한 것

1. 환경 설정에서 공식 문서 도메인과 선택한 API 도메인 접근을 적용합니다. 키 값은 채팅이나 Git에 쓰지 않습니다.
2. 초기 검증 후보 B.AI와 OpenRouter 키를 각각 `BAI_API_KEY`, `OPENROUTER_API_KEY`로 안전하게 등록합니다. 비용 조건이 확인되지 않으면 그 제공자는 제외하고 다른 후보를 선택합니다.
3. 정확한 계정의 요금제·결제 연결·자동 충전·무료 초과 시 동작을 확인합니다. 키가 있다는 사실만으로 무료를 판정하지 않습니다.
4. 최소 두 제공자의 현재 모델 ID·지원 기능·가격·무료 한도·공식 근거·확인 기한을 모델 설정에 기록합니다. 기간제 무료는 정확한 종료 시각/시간대가 필요합니다.
5. `--check` 후 비민감 합성 문장으로 각 경로의 JSON 응답을 시험하고, 제공자 사용량/청구 기록에서도 비용 0원을 확인합니다. 호출 성공은 무료 증거가 아닙니다.
6. MAGI의 서로 다른 모델 계열 응답, 나라장터 공고 key 보존·누락 처리, 한도 초과 대체를 검증합니다.

현재 실제 모델을 임의로 활성화하지 않았습니다. 가입·결제 변경·유료 전환은 수행하지 않습니다. 모델 순위는 공개 평가와 합성 작업 결과가 모인 뒤 정하며, 서로 비교할 수 없는 벤치마크 점수를 임의로 합산하지 않습니다.
