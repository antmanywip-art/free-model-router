# Free Model Router

MAGI와 나라장터 감시장치를 위한 개인용 무료 AI API 라우터입니다. Codex 외 추가 비용 0원, 기간제 무료 허용, 무료 여부가 불명확하면 호출하지 않는 정책을 사용합니다.

## 현재 상태

2단계의 라우터·클라이언트 연결을 구현하고 모의 제공자를 이용한 HTTP 통합 검증을 준비했습니다. **실제 제공자의 최신 가격, 계정 무료 조건, 실호출은 아직 검증하지 않았습니다.** 운영 설정의 모델 목록은 의도적으로 비어 있으며 `/readyz`는 503을 반환합니다. 이를 실제 서비스 준비 완료로 해석하지 마세요.

제공자 후보 10곳은 `config/provider_candidates.json`, OpenAI 호환 접속 설정 7곳은 `config/router.json`에 있습니다. 후보/접속 설정 등록은 무료 검증이나 활성화를 뜻하지 않습니다. 새 계정 가입 전에 `docs/PROVIDERS.md`를 확인하세요. OCI 배포는 3단계이며 수행하지 않았습니다.

## 설치·실행

Python 3.11+가 필요합니다. Python 3.12/Linux x86_64에서 검증합니다. 기존 OCI Python 3.9에는 그대로 설치할 수 없으므로 3단계에서 지원 런타임을 마련해야 합니다.

```sh
cd /workspace/free-model-router
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-build-isolation --no-deps -e .
.venv/bin/python -m free_router --check
.venv/bin/python -m free_router
```

서버는 `127.0.0.1:3100`에서만 수신하며, 백그라운드 데몬이나 예약 작업을 설치하지 않습니다. 운영 HTTPS는 추후 OCI Caddy가 담당합니다. 프로세스는 새 클라우드 작업에 복원되지 않으므로 다시 시작해야 합니다. `requirements.lock`은 직접·전이 의존성 버전을 고정합니다. TLS·패키지 검증을 끄지 않습니다.

## 로컬 검증

```sh
.venv/bin/python -B -m unittest discover -s tests -v
.venv/bin/python -B scripts/integration_smoke.py --magi /workspace/magi --nara /workspace/nara-monitor
```

통합 검증은 임시 가짜 API 두 곳과 라우터를 **루프백에서만** 실행합니다. MAGI 두 평가자, 나라장터 선별·요약의 실제 Python 호출 경로를 거칩니다. 외부 AI, 수집 사이트, SMTP는 호출하지 않습니다. MAGI/나라장터 소스는 각 비공개 저장소에 유지하며 이 저장소로 복제하지 않습니다.

## 인터페이스

| 경로 | 용도 |
|---|---|
| `GET /healthz` | 프로세스 생존 확인; 인증 없음 |
| `GET /readyz` | 인증 가능한 클라이언트와 조건에 맞는 무료 경로 존재; 없으면 503 |
| `GET /v1/models` | 현재 클라이언트가 사용할 수 있는 활성 별칭/지정 경로 |
| `POST /v1/chat/completions` | Bearer 인증, 텍스트 채팅·JSON 객체·함수 도구 호출·SSE |
| `GET /v1/usage` | 해당 클라이언트의 집계 사용량만 반환 |
| `POST /admin/reload` | 별도 관리자 키로 설정 검증 후 교체; 오류 시 기존 설정 유지 |

현재 클라이언트는 `stream=false`, `response_format={"type":"json_object"}`를 사용합니다. 완전한 JSON 검증을 위해 JSON 모드와 스트리밍의 동시 사용은 거부합니다. 이미지·PDF 원문, Responses API, embeddings, 임의 OpenAI 확장 필드는 미지원입니다. 나라장터는 추출된 첨부 텍스트를 전달합니다.

`best-general`, `best-coding`, `best-fast`, `magi-a`, `magi-b`, `nara-text`는 운영자가 검증한 모델 ID 목록으로 채웁니다. 순서는 용도별 평가로 정하며 근거 없는 성능 점수를 만들지 않습니다. 직접 지정 경로는 실패해도 다른 모델로 바꾸지 않습니다. `router.exclude_families`로 이미 사용한 모델 계열을 제외할 수 있습니다. MAGI 별칭 두 개는 서로 다른 모델 계열로 구성하세요.

## 무료 정책·한도

활성화에는 정확한 모델 ID, 기능·문맥·출력 한도, 계정 무료 자격, 제공자 측 과금 방지 수단, 공식 근거, 확인 시점/기한이 필요합니다. `model.template.json`은 비활성 작성 예시입니다.

- `free.status=free`, `enabled=true`, 계정 검증과 키가 모두 있어야 호출합니다.
- 가격 확인의 유효기간은 최대 7일, 프로모션 종료는 별도로 검사합니다. 운영에서는 변경 속도에 맞춰 더 짧게 설정하세요.
- 유료·미확인·만료 모델은 대체 대상으로도 사용하지 않습니다. 모든 경로 소진 시 503입니다.
- 단순 예산 알림이나 잔액 표시는 과금 방지 수단이 아닙니다. 제공자의 무료 전용 엔드포인트, 결제 비활성화 또는 실제로 강제되는 0원 한도가 필요합니다. 설정의 검증 표시는 사람이 확인한 근거를 기록하며 외부 결제 상태를 자동 조회하는 기능은 아직 없습니다.
- 동일 계정의 모델·제공자는 `quota_group`을 공유합니다. 날짜는 UTC 기준입니다. 설정의 기본 호출 상한은 보수적인 **로컬 상한**으로, 제공자의 공식 무료 할당량이 아닙니다.
- 기본 동시 요청 2개, 최대 대체 시도 3회, 전체 시간 제한 90초, 요청 512KiB, 응답 4MB입니다. 큐를 무한히 쌓지 않고 초과 시 429를 반환합니다.
- `429`의 Retry-After는 최대 24시간까지 반영합니다. 인증·결제 오류는 계정을 24시간 일시 제외합니다. 장애 대체는 응답을 시작하기 전에만 수행합니다. 스트리밍 도중 실패하면 오류 이벤트를 보내고 재생하지 않습니다.
- 프롬프트를 잘라 넣지 않습니다. UTF-8 바이트 수와 메시지 오버헤드로 보수적으로 입력 크기를 검사합니다. 실제 제공자 토큰 계산기와 동일한 계산은 아닙니다.

## 인증·저장·운영 제한

`ROUTER_MAGI_KEY`, `ROUTER_NARA_KEY`는 서로 다른 32자 이상의 무작위 키입니다. `ROUTER_ADMIN_KEY`는 선택적이며 클라이언트 키와 달라야 합니다. 실제 값은 Git 밖에서 프로세스 환경으로 주입합니다. 앱은 `.env`를 자동으로 읽지 않습니다. 예시 키를 운영에서 사용하지 마세요.

제공자 키 변수 이름은 `config/router.json`에 있습니다. HTTPS 검증을 유지하며 업스트림 리다이렉트를 따라가지 않습니다. 키가 들어 있는 제공자 오류 본문을 응답·로그로 전달하지 않습니다. 접근 로그는 기본 비활성입니다.

SQLite에는 요청·실패 횟수와 제공된 토큰 수만 일별 집계하며 31일 보존합니다. 프롬프트, 응답 본문, 인증키는 저장하지 않습니다. 스트리밍 토큰 사용량은 현재 집계하지 않으므로 토큰 집계가 완전한 과금 장부는 아닙니다. 카운터·쿨다운은 재시작 후 유지됩니다. 운영은 단일 프로세스/워커를 전제로 합니다.

설정 reload는 진행 중 요청이 끝난 이후 요청부터 적용됩니다. 환경변수·HTTP 본문 상한 등 실행 환경 변경은 재시작하세요. 모델 목록/ready 성공만으로 실제 제공자의 가용성·무료 여부가 입증되지는 않습니다.
